# Software factory positioning

The previous hero led with agent memory. The revised page leads with an agentic
software factory and meets clients at their current stage: assistants, first
production agents, a governed platform on a business ontology through Quipu,
then coding agents working inside CI and review gates. Specs and evaluations
set the contract, and humans approve at the gates.

The existing logo, colors, diagrams and playground remain. There is no displayed
portrait. The experience and open research provide the evidence for the offer.

with four stages, both diagrams, no horizontal overflow and no displayed portrait.
The existing playground contract passes URL, resize, invalid-message and mobile
checks. The browser runs are local previews, not evidence of deployed acceptance.
